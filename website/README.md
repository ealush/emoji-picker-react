# emoji-picker-react website

Demo and marketing site, deployed to GitHub Pages from `master` via
`.github/workflows/website.yml`.

```bash
cd website
npm ci
npm run dev
```

The site consumes the local repository package (`file:..`), copied with `install-links=true`. Build the library at the repository root before installing the website. The PR workflow builds and uploads the candidate static site; deployment runs only from master.

Recipe source downloads and the shadcn registry item are generated by `npm run designs` and `npm run registry` at the repository root.
